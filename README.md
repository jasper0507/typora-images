# typora-images

Static image assets for personal Markdown notes.

## Access

Files are served via public CDN links (jsDelivr → this repository).  
Anyone who has a full image URL can view that file. There is no authentication on individual assets.

This repository is intentionally **not** an album, gallery, or documentation site.

## Contents

- Images are stored under non-obvious path prefixes.
- Filenames are time-based identifiers, not original names.
- Do not commit tokens, credentials, or private configuration.

## Privacy expectations

| What is private | What is not |
|-----------------|-------------|
| Local PicGo token & config on your machine | Any image once its URL is known |
| Repo issues / wiki (disabled) | Public git history & file listing on GitHub |
| Intent / note context (not documented here) | CDN and raw GitHub responses for existing URLs |

If an image must not be world-readable, **do not host it here**. Use local-only attachments or a private storage service with access control.
